# Cepte Menü — menü teması önizlemeleri

Dört menü temasının çalışan önizlemesi. Örnek veriyle doldurulmuş, statik HTML.

| Tema | Kime |
| --- | --- |
| Vitrin | Görseli olan restoran, kafe |
| Liste | Çok ürünlü fırın, market, büfe |
| Zarif | Restoran, otel, fine dining |
| Günbatımı | Havuz başı, sahil, büfe |

`telefon.html` dördünü telefon genişliğinde yan yana gösterir.

## AYAR çentiği

Her önizlemenin sağ kenarındaki çentikten tema, açık/koyu görünüm, ana renk
ve tek tek renk rolleri denenebilir; altında yazı/zemin kontrast oranları
listelenir.

Çentik **yalnızca bu önizlemelerde** vardır. İşletmeye giden canlı menüde
bulunmaz; orada renk ve tema yönetim panelinden gelir.

## Not

Bu depo yalnızca gösterim amaçlı üretilmiş çıktıyı içerir. Ürün kaynağı ve
geliştirme notları ayrı, özel depodadır.
